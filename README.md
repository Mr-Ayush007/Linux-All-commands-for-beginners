# Linux Commands Reference Guide

A clean, structured, and easy-to-use reference repository for essential Linux commands. Whether you are a beginner looking to understand terminal basics or a developer needing a quick lookup for file permissions, user management, and advanced networking, this guide has you covered.

---

## 📁 Repository Structure

This repository is organized into individual sections for quick reference:

1. **[Basic Navigation & System Info](01_basic_navigation.txt)**
   - Fundamental commands to move around the file system, view files, and check system status (`pwd`, `ls`, `cd`, `mkdir`, `touch`, `cat`, `less`, `echo`).
2. **[File & Directory Management](02_file_directory_management.txt)**
   - Commands for copying, moving, deleting, searching, and compressing/extracting files (`cp`, `mv`, `rm`, `find`, `grep`, `tar`, `unzip`).
3. **[File Permissions & Ownership](03_file_permissions.txt)**
   - Multi-user security, access rights, and permission masks (`chmod`, `chown`, `chgrp`, `umask`).
4. **[User & Group Management](04_user_group_management.txt)**
   - Tools for managing system accounts, passwords, groups, and privileges (`useradd`, `passwd`, `usermod`, `userdel`, `groupadd`, `su`, `sudo`).
5. **[System Monitoring & Processes](05_system_monitoring.txt)**
   - Real-time performance tracking, process control, and disk/memory checks (`top`/`htop`, `ps`, `kill`, `df`, `du`, `free`, `systemctl`, `journalctl`).
6. **[Advanced Networking & Remote Connections](06_advanced_networking.txt)**
   - Network troubleshooting, DNS queries, secure remote copy, and server management (`ip`, `ping`, `curl`/`wget`, `ss`, `ssh`, `scp`, `rsync`, `dig`, `traceroute`).

---

Clone this repository to your local machine to keep these reference guides handy in your terminal or text editor:

```bash
cd linux-commands-guide
```
